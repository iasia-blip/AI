1. Описание выбранной игры
Была выбрана игра Connect Four на вертикальном поле 6x7. 
Игроки по очереди сбрасывают фишки в одну из 7 колонок (0–6).
Фишка автоматически падает в самую нижнюю свободную ячейку выбранной колонки.
Побеждает тот, кто первым выстроит 4 свои фишки подряд по горизонтали, вертикали или диагонали.

2. Как работает алгоритм Minimax
Minimax - это рекурсивный алгоритм принятия решений для двух игроков с противоположными целями (игры с нулевой суммой):
1. Максимизатор (ИИ): стремится выбрать ход, который даст максимальную оценку позиции.
2. Минимизатор (Человек): предполагает, что соперник сделает наилучший ответный ход, минимизирующий выгоду ИИ.

3. Оценочная функция `Evaluate(state)`
Используется эвристика с ограничением глубины:
Победа ИИ: +1000 очков.
Победа Человека: -1000 очков.
Контроль центра: За каждый символ ИИ в центральной (3-й) колонке даётся +5 очков.


4. Ограничение глубины поиска
Используется глубина поиска `depth = 4`.
Причина: На каждом шаге доступно до 7 вариантов ходов. На глубине 4 алгоритм анализирует порядка 7^4 = 2401 состояний, что выполняется за доли секунды без задержек.
